Static ad prompts

20 SILT statics, each modelled on a Supply6 static from the teardown, with a ChatGPT image prompt and Meta ad copy. Ones based on Supply6 ads that ran 20+ days come first: start there.

1. Attach the real pack

Save these two photos, then attach the one the prompt names in ChatGPT so it uses our real box and stick:

  • Mornings pack photo (1. Mornings_PDP.png)
  • Nights pack photo (1. Nights_PDP.png)

Open the photo, then right-click and save it.

2. Paste the prompt

Copy the prompt, paste it with the photo attached, and generate. Make 2 or 3 versions of each so Meta can test them against each other in one ad (dynamic creative).

3. Fix and resize

If a word comes out wrong:

Fix only the headline so it reads exactly: "..." Keep everything else the same.

For Stories and Reels:

Make a 9:16 version: same design, extend the background at the top and bottom, keep all text in the middle.

Before it goes live

  • Check every dose on the image against the box.
  • No cure or treatment words. Doses as "the dose used in studies".
  • Check the pack wasn't redrawn. If it was, regenerate or place the real pack photo on top in Canva.
