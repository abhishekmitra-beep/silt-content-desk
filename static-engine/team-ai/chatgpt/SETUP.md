# SILT Statics GPT (ChatGPT)

Each person sets this up once. It needs a ChatGPT plan that can create GPTs.

1. Go to https://chatgpt.com/gpts/editor and choose **Configure**.
2. **Name:** SILT Statics.
3. **Instructions:** paste everything in `GPT_INSTRUCTIONS.txt`, which is next to this file.
4. **Actions:** choose Create new action, then paste the contents of `openapi.json`. Authentication: None.
5. Save it as **Only me**, or **Anyone with the link** inside the team.

How to use it: tell it an idea, for example "6 statics about wedding season wrecking sleep". It reads the house rules, makes the statics on the Static Engine and sends you the link.
